The handoff breaks between assignment and return.

The lead sends a brief. Creators generate in their own tools. Work comes back as files, links, screenshots, and half-remembered prompt notes.

At review time, the leader has to reconstruct the context: which input was used, what the creator was asked to try, which prompt produced the take, and what decision was made.

Nitrate fixes that one break. A packet carries the assignment out, and the return comes back with the same context still attached.

The packet keeps the trail intact.

It is the assignment object that travels from the project leader to the creator’s clanker and back to review.

What to make

Campaign brief, creative direction, constraints, banned looks, and review criteria.

What to use

Input assets, references, brand material, previous returns, and tool-specific guidance.

Who does what

Creator assignments mapped to the clanker or agent workspace they already use.

How it returns

Required folders, media files, prompt notes, tool/model context, and handoff material.
