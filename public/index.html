nitrate starts as a clanker plugin. Each creator installs it, logs in, and receives the team lead's brief, input assets, and expected output structure inside their AI workspace. Finished work syncs back for lead review.

Install the plugin

Add nitrate to the clanker each creator already uses for Claude, Claude Code, Higgsfield Supercomputer, and local media runs.

Log in

The plugin asks the creator to log in, then shows packets assigned to them by the team lead.

Sync returns

When the creator finishes, the plugin sends media, prompts, notes, and handoff folders back to the lead's review room.

Keep the creation tools. Add team control.

The missing shared drive for AI creators.

Shared drives store files after the fact. nitrate starts earlier: it tells every creator what to make, what inputs to use, how to organize the output, and where the work comes back.
