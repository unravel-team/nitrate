Put the handoff inside the AI coding agent.

Nitrate is collaboration for AI video agencies: a leader sends one real brief and its source files; a creator pulls them into the agent they already use; the returned draft arrives ready to review.

The fast path to valueAttach one actual input file, send one creator invite, and watch their AI coding agent pull a verified workspace. That is the first proof the campaign is now shared.

Use the agent workspace your team already has.

Codex

Add the Nitrate marketplace, then install the self-contained plugin. The handoff commands and connection stay inside Codex.

codex plugin marketplace add unravel-team/nitrate
codex plugin add nitrate@nitrate-local

Nitrate is the collaboration layer and working DAM for AI agents. Your creators still make media in Higgsfield, Runway, fal, Replicate, or any other tool; Nitrate carries the brief, inputs, output structure, prompt, notes, and review decision around that work.

Leader → creator → review.

  1. Leader logs inConnect Nitrate from Codex or Claude Code.
  2. Handoff real workAttach the client brief, source files, expected folders, and review rules.
  3. Creator pulls inviteA single-use invite writes a verified workspace and AGENT_BRIEF.md.
  4. Creator returns draftThe actual render returns with its prompt, tool, notes, and agreed destination attached.
  5. Leader decidesApprove, reject, or request changes on the exact returned work.

What each person asks their agent to do.

Agency lead

Login once, then hand off the actual campaign. Nitrate will not create an invite until at least one real input file is uploaded and verified.

nitrate login --email maya@agency.com --role leader
nitrate handoff --name "Northwind launch" --brief "Create a 15s launch ad" --input ./brand-guide.pdf --input ./product-reference.mov --to nia@agency.com --task "Make the commuter-story route"

Creator

Open the one-time invite in Codex or Claude Code. Build in your preferred media tool, then return the finished file with the creation context.

nitrate pull <one-time-invite-url> --dir ./northwind
nitrate return ./northwind/renders/commuter-v1.mp4 --dir ./northwind --tool "Higgsfield Supercomputer" --prompt "…the prompt used…" --notes "…what the lead should review…"

Leader review

Every draft has its creator, prompt, tool, notes, and source handoff intact. Record the decision directly on the returned work.

nitrate review <return-id> --decision request-changes --note "Warm the grade; keep the approved end card."
