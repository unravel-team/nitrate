Leader workflow

The lead controls the packet. The plugin pushes the brief, assets, output contract, and task to every creator clanker.

1. Create packetClient brief, inputs, folders, review criteria.nitrate init-agency
2. Push to creatorsEach creator gets the same source of truth.nitrate push
3. Watch returnsSee who pulled, worked, blocked, or returned.nitrate next
4. Send next passTurn review decisions into the next packet.nitrate packets

Team member workflow

The creator stays inside the clanker. Pull the packet, work the generated folder, and sync one clean return back.

1. Ask what’s nextThe plugin tells you the current assignment.nitrate next
2. Pull packetNitrate creates folders and AGENT_BRIEF.md.nitrate pull
3. Mark workingLead sees the clanker is active.nitrate status --status working
4. Sync returnMedia, prompt, model, and notes go back together.nitrate sync
