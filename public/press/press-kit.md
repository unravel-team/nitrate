# nitrate press kit

_Private-preview fact sheet. Last updated August 26, 2026._

## One-line description

nitrate is an AI coding agent plugin and collaboration layer for AI media teams. Creators log in from the plugin, receive briefs and input assets inside their AI workspace, then sync returned work back for review.

## Launch facts

- **Status:** Private design-partner preview.
- **Primary users:** Media team leads, producers, creative directors, and AI creators.
- **Supported creation surfaces:** Claude, Claude Code, Higgsfield Supercomputer, local AI coding agents, and tools that export image, video, or audio.
- **Integration status:** File-based returns are available in the MVP. Direct product integrations and AI coding agent sync are roadmap goals.
- **Entry point:** AI coding agent plugin login.
- **MVP:** A runnable local web app proving plugin login, brief packets, input assets, output-folder contracts, creator assignments, returned work, decisions, comments, templates, and share links.
- **Use-case framing:** "Generating understanding" means turning scattered AI creation into shared direction, clean returns, and reviewable decisions.
- **Production architecture target:** Cloudflare Workers, D1 for transactional metadata, R2 for media objects, and Queues for derivatives and sync jobs.
- **Pricing:** Not announced.
- **Funding:** Not announced.
- **Compliance:** C2PA inspection/export and EU AI Act-oriented reporting are roadmap objectives, not certifications or legal assurances.

## Problem

Everyone on the team can create media now, but collaboration is missing. Work sits in personal Claude chats, Claude Code runs, Higgsfield batches, downloads folders, and local AI coding agents. Team leads cannot reliably push the same brief to everyone, enforce the expected return structure, or review outputs with the context needed to decide.

## Product approach

nitrate starts with the lead's packet: brief, inputs, references, constraints, assignments, and expected folders. That packet is pushed to creators' AI coding agents. Creators finish the work in their preferred AI setup and return media, prompts, notes, and handoff files back into one reviewable project.
